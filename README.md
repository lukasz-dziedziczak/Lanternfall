
# Lanternfall

**A third-person ninja stealth game built with Unreal Engine 5.9.**

Developed by **Emberline Studios** for the **2026 Epic AI MegaJam**.

---

## About the Game

Lanternfall is a single-player ninja stealth game inspired by classic infiltration games such as Tenchu.

Infiltrate a heavily guarded Japanese temple, eliminate enemies from the shadows, retrieve a valuable relic, and escape without being detected.

The central mechanic revolves around manipulating light and darkness. Extinguishing lanterns creates opportunities to hide and move unseen, but guards will investigate unexpected changes in their environment.

Every extinguished light creates both an opportunity and a risk.

## Gameplay Features

The following features are planned for the game:

- **Third-Person Stealth** - Sneak, crouch, sprint, and navigate enemy territory.
- **Dynamic Light Manipulation** - Extinguish lanterns using shuriken to create areas of darkness.
- **Enemy AI** - Guards patrol, investigate disturbances, search suspicious areas, and pursue detected intruders.
- **Stealth Assassinations** - Eliminate unsuspecting enemies using contextual takedowns.
- **Ninja Tools** - Use shuriken and a grappling hook to navigate the environment.
- **Melee Combat** - Defend yourself when stealth fails.
- **Environmental Navigation** - Explore rooftops, courtyards, and hidden routes.
- **Mission Objectives** - Infiltrate, recover the target, and reach the extraction point.
- **Mission Ranking** - Earn a performance rating based on your actions.

## Getting Started

### Requirements

- Unreal Engine 5.9
- Windows development environment
- Visual Studio 2022 with Unreal Engine development tools (for C++ development)
- Git
- Git LFS (recommended for large binary assets)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Lanternfall.git
   ```

2. Open the project directory.

3. Launch `Lanternfall.uproject` using Unreal Engine 5.9.

4. Allow Unreal Engine to generate any required project files, compile shaders, and prepare the project.

5. Open the project's main level to begin development or testing.

Additional plugins and third-party assets may be required depending on the current development state.
